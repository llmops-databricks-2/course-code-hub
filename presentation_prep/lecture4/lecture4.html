Manual span

def add_manually(x: int, y: int):
    with mlflow.start_span(
        name="add_numbers"
    ) as span:
        span.set_inputs({"x": x, "y": y})
        result = x + y
        span.set_outputs(result)
        return result

add_manually(2, 3)

A parent span and two child spans

@mlflow.trace(span_type=SpanType.TOOL)
def search_database(query):
    return ["Example paper"]

@mlflow.trace(span_type=SpanType.LLM)
def call_llm(prompt):
    return "Simulated answer"

@mlflow.trace(span_type=SpanType.CHAIN)  # PARENT
def process_query(query):
    results = search_database(query)  # CHILD 1
    return call_llm(f"{query}: {results}")  # CHILD 2

process_query("Find papers on agents")

Calibration to one person is not enough

A COMMON PITFALL

Optimize for agreement
with one human

The judge can learn that person’s preferences, blind spots and inconsistent labels.

High agreement alone does not establish that it can replace a reviewer.

THE DECISION WE NEED TO MAKE

Is it good enough
to replace a human?

Compare the judge with multiple qualified reviewers using the same rubric and context.

Test on fresh examples and account for the cost of mistakes.

Define replacement for a specific task and review decision, not for human judgment in general.

A single expert can define a useful rubric, but matching their labels alone is not evidence that an LLM judge can replace a human reviewer for the wider task. Discuss the risk of learning individual preferences, and validate on held-out examples with multiple qualified reviewers.

EVALUATION

Is an LLM judge good enough to replace a human?

Alt-Test

  1. Leave one human annotator out.
  2. Compare the LLM and that human with the same remaining annotators.
  3. Repeat for every human.
  4. Apply the cost-benefit adjustment and false discovery rate (FDR) correction.
Winning rate ≥ 0.5

Supports replacement for the tested task and settings, after the statistical tests.

Calibration sample: 3+ humans; the paper discusses 50–100 items. Sample needs vary.

Match instructions

Give humans and the LLM the same written rubric and context.

Clarify class definitions

Inspect confused class pairs. Refine ambiguous definitions before blaming the model.

FDR correction controls false “wins” across multiple human comparisons.

Calderon, Reichart & Dror · ACL 2025 · Alt-Test paper

Alt-Test compares each held-out human and the LLM against the same remaining annotators. The procedure includes a cost-benefit adjustment and false discovery rate (FDR) control. Its winning rate is the proportion of human comparisons won after hypothesis testing, not raw example-level accuracy. A winning rate of at least 0.5 supports replacement only under the tested task and settings. The paper discusses at least three annotators and 50–100 examples; sample requirements vary.
